# How To — что дать AI в новом треде

## Что это

Инструкция для **человека** (тебя), что скопировать в **новый чат** с AI,
если текущий тред исчерпал лимит токенов.

После копирования AI должен:
1. Понять формат Jira
2. Понять текущий этап
3. Продолжить работу без «раскачки»

## Что скопировать

**Минимум** — три вещи:

1. Файл `howTo.md` (этот)
2. Файл `readme.md` текущей активной подзадачи (например, `Jira.001.01/readme.md`)
3. Файл `Jira.001/readme.md` (Epic)

**Если есть специфика** — добавить:

4. Снапшоты `Snapshots/Before/*.puml` и/или `Snapshots/After/*.puml`
5. Эталон `docs/_threads/sequence-acceptance.md`
6. Список открытых тикетов (строкой)

## Формат сообщения (шаблон)

```md
Продолжаем с метки «Исправление sequence диаграмм».

## Файлы Jira

<вставить readme.md текущего эпика>
<вставить readme.md текущей подзадачи>

## Текущий этап

<этап из таблицы ниже>

## Открытые тикеты

- Jira.001.03 — status: In Progress
- Jira.001.05 — status: Open
…

## Правила формата вывода

<вставить блок «Формат вывода» ниже>

## Формат вывода (вставить в новый тред)

ФОРМАТ ВЫВОДА — строго соблюдать:

1. Каждый файл — отдельный блок:

   ═══ ФАЙЛ: <путь/к/файлу> ═══
   \`\`\`\`<язык>
   … содержимое …
   \`\`\`\`
   ═══ КОНЕЦ: <путь/к/файлу> ═══

2. Внешний фенс — ЧЕТЫРЕ бэктика (\`\`\`\`), чтобы вложенные \`\`\` (тройные) не разрывали блок.

3. Диаграммы — ДВА формата для каждой:
a) ASCII-арт в (тройные бэктики) 
b) Mermaid в mermaid (для GitHub/GitLab/VS Code)

4. Никаких вставок реального кода. Только:
• имена интерфейсов, классов, методов
• пути к файлам
• короткие примеры синтаксиса (// context: …)

5. Тон: технический, без воды.

6. Нумерация узлов — <Parent>.<Child>.<Grandchild>, уникальна в пределах уровня. Корень — без номера.

7. Разбивка на блоки. После каждого блока — «Что дальше» с перечислением следующих файлов и предложением сказать «дальше».

8. Ссылки — только внутренние (../path/file.md). Никаких внешних.

```

## Этапы (текущий статус)

Обновляй вручную при возобновлении.

| #   | Этап                             | Статус |
| --- | -------------------------------- | ------ |
| 0   | Критерии приёмки                 | Open   |
| 1   | Реестр проблем (снапшоты Before) | Open   |
| 2   | Красные тесты                    | Open   |
| 3   | Правки модели (Jira.001.01–07)   | Open   |
| 4   | Правки парсера (Jira.001.08)     | Open   |
| 5   | Сверка с эталоном                | Open   |
| 6   | Регрессия R1–R8                  | Open   |
| 7   | Документирование                 | Open   |

## Снапшоты

После выполнения этапа 1 в папке:

ContextBrowserTests/Snapshots/
├── Before/ ← как есть, до фиксов
└── After/ ← после фиксов (появится на этапе 5)


Список файлов для снапшотов — 8 штук (R1–R8), см. `Jira.001/readme.md`.

## Ссылки

- `Jira/readme.md` — структура Jira
- `Jira/backlog.md` — чекбоксы
- `Jira.001/readme.md` — Epic
- `Jira.001.01/readme.md` — активная подзадача
- `docs/_threads/sequence-acceptance.md` — критерии приёмки (создаётся
  на этапе 0)

## Если AI сбился с формата

Скажи:

```md
Ты отклонился от формата. Вернись к инструкции:
— внешний фенс 4 бэктика
— маркеры ═══ ФАЙЛ ═══ … ═══ КОНЕЦ ═══
— диаграммы в двух видах (ASCII + mermaid)
— блок «Что дальше» в конце
```


## Что НЕ надо давать AI

- ❌ Весь код целиком — только файлы, которые правим
- ❌ Историю предыдущих чатов — только текущее состояние
- ❌ Логи компиляции — только если падают тесты
- ❌ Ссылки на внешние ресурсы — контекст самодостаточен
