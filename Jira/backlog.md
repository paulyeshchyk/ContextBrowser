# Backlog — чекбоксы

Список эпиков и подзадач с отметкой о завершении.
Обновляется **в момент** завершения задачи, не задним числом.

## Формат

```
- [ ] Jira.001 — Название эпика
  - [ ] Jira.001.01 — Название подзадачи
  - [ ] Jira.001.02 — Название подзадачи
- [x] Jira.000 — Закрытый эпик (пример)
```

## Легенда

- `[ ]` — не завершено
- `[x]` — завершено
- `[~]` — Won't Fix / отменено
